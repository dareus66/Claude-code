# Calcolatrice di Conversione Unità

Una calcolatrice web intuitiva e moderna per convertire varie unità di misura.

## Caratteristiche

- **7 Categorie di Conversione:**
  - 📏 **Lunghezza**: metri, chilometri, centimetri, millimetri, miglia, yard, piedi, pollici
  - ⚖️ **Peso**: chilogrammi, grammi, milligrammi, tonnellate, libbre, once
  - 🌡️ **Temperatura**: Celsius, Fahrenheit, Kelvin
  - 💧 **Volume**: litri, millilitri, metri cubi, galloni, pinte, once fluide
  - 📐 **Area**: metri quadrati, chilometri quadrati, ettari, acri, piedi quadrati
  - 🚀 **Velocità**: metri al secondo, chilometri all'ora, miglia all'ora, nodi
  - ⏱️ **Tempo**: secondi, minuti, ore, giorni, settimane, anni

- **Interfaccia Intuitiva:**
  - Design moderno e responsive
  - Conversione in tempo reale
  - Pulsante per scambiare rapidamente le unità
  - Visualizzazione chiara del risultato

## Come Usare

1. Apri il file `index.html` nel tuo browser
2. Seleziona la categoria di conversione desiderata
3. Inserisci il valore da convertire
4. Seleziona l'unità di partenza e quella di destinazione
5. Il risultato apparirà automaticamente!

## Funzionalità Tecniche

- Conversioni precise con arrotondamento a 6 cifre decimali
- Gestione speciale per le conversioni di temperatura (non lineari)
- Design responsive per dispositivi mobili e desktop
- Nessuna dipendenza esterna - funziona offline!
